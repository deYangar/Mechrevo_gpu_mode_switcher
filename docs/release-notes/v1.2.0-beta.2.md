机革显卡模式切换妙妙小工具，v1.2.0-beta.2（预发布测试版）。

接着 beta.1 那位 40 系用户的反馈往下修。这次的问题是：核显省电之后点「独显直连」切不回去，也不提示重启。日志显示命令其实都发出去了、控制中心服务也都确认收到了，卡住的地方在后面一步——工具切直连前会先把混合模式恢复完整、等独立显卡重新上线，而 40 系机型没有「不重启就切」的通道，显卡要等重启才会回来，工具就一直在那里等，等到超时报了个「失败」了事。重启的确认框排在这步之后，所以永远轮不到它出场。

## 修复：核显省电后点「独显直连」没反应、不提示重启

查了控制中心自己的切换逻辑作对照：它从省电切直连就是直接下直连指令然后请用户重启，中间不做「先恢复混合再继续」的等待。本版照此对齐：

- 省电状态下点「独显直连」：先把省电的记账归位，直接下直连指令，弹出熟悉的重启三选（立即重启 / 稍后重启 / 取消）。一次重启直接落到独显直连，不再空等显卡上线。50 系行为不变，只是少等几秒。
- 三选里的「取消」现在能真正取消：从省电发起的直连，取消后连省电的记账一并恢复原状，和点按钮之前一模一样，无需重启。
- 单独点「混合模式」退出省电：40 系若需要重启才能让显卡回来，不再报失败，而是明确提示处于待重启状态，可选立即重启或稍后自行重启。50 系照旧秒级切回。

40 系上「省电状态下直接下直连指令」这一步还没有真机验证过（50 系与控制中心的行为都有实测或源码依据），继续以预发布形式征集反馈。卡在省电态的 40 系用户用旧版也能解困：重启一次会落回混合模式，再点「独显直连」就会正常提示重启。

另有一个小变化：`--eco off` / `--hybrid` 在需要重启兑现时，退出码从 1 改为 0（切换已交接成功，重启即成），写脚本判断的朋友注意。
