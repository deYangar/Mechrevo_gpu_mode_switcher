机革显卡模式切换妙妙小工具，第一个版本。

给机械革命（同方模具 30/40/50 系）机型用的独显占用查看 + 显示模式切换工具。单文件 exe（约 12 MB），双击运行，UAC 确认一次即可，无需安装。

## 功能

- **查占用**：哪个进程在占用独立显卡。任务管理器同款数据口径，另带驱动层持有者扫描——不占图形上下文、只挂显卡传感器的监控软件（HWiNFO 一类）也能现形。支持持续监视，新持有进程冒头即报。
- **核显省电**：独显整卡断电，续航最长。50 系与 40 系双显三模机型支持；30 系和 40 系常规机型没有这个硬件档位，工具会自动改走官方运行时省电（断输出、降刷新率、设备软禁用，非整卡断电）。
- **独显直连 / 混合模式**：MUX 硬件切换，重启后生效。切换前问你是立即重启、稍后自己重启还是取消——取消会真的撤回指令恢复原样，不是嘴上说说。
- **状态凭证**：当前显示模式的判定依据（内屏路由、设备状态、GCU 意图回报）全量展示，切没切到位一眼可查。

## 适用机型

| 代际 | 核显省电 | 直连 ⇄ 混合 |
|---|---|---|
| 30 系 | 运行时省电 | ✓ |
| 40 系双显三模机型 | 整卡断电 | ✓ |
| 40 系常规机型 | 运行时省电 | ✓ |
| 50 系 | 整卡断电 | ✓ |

宝龙达模具机型（蛟龙 30 系部分、WJIE14XA、星耀、UMI/NUC）不走 GCU 协议，工具会直接报不支持，不会发命令。分不清自己的 40 系是哪种档位，跑一下 `--gcu-info` 即可。

## 下载

下方 Assets 的 `gpu_mode_switcher.exe`。想看源码或用命令行（纯 Python 标准库，无需装包）：`python dgpu_detective.py --help`。

## 注意

- 切换前保存手头工作，游戏、渲染这类占用独显的程序会提示先关。
- 切换功能在 50 系上真机实测最充分；40 系双显三模机型协议与官方安装包逐一核对一致，待真机反馈；两类机型遇到问题欢迎提 issue，附上软件旁边 logs 目录的日志。
- 本工具向本机 GCU 服务发送与官方控制中心完全相同的命令，不碰协议之外的东西；无遥测、无联网。
