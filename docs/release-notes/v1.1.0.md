机革显卡模式切换妙妙小工具，v1.1.0。

这一个版本只加了一件事：日志保留策略。其余与 v1.0.0 一致，老用户直接换新 exe 就行，旧日志不会被动。

## 新增：日志保留策略

每次切换模式，工具都会在软件旁边的 logs 目录留一份完整记录，方便排查「卡在哪一步」。这份留档之前只增不减，用久了会攒下一堆旧文件。现在日志区上方多了一个「日志保留」下拉框，五个选项：

- 不开启：切换不再写日志文件，界面上的输出不受影响
- 保留 3 天 / 7 天 / 30 天：超龄的旧日志自动清理，打开软件和每次切换后各清一次
- 不自动清理：维持原来的行为

默认「保留 30 天」。单个日志大约 1~3 KB，三十天下来也就几百 KB，排查问题足够回溯；想完全不留痕就选不开启，想自己管就选不自动清理。选择会记在软件旁边的 settings.json 里，下次打开自动沿用。

清理只动 logs 目录下超龄的 .txt 留档。个别文件删不掉（比如正被别的程序打开）会在界面上如实报出来，不会悄悄跳过。
